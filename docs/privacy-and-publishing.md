# 隐私与发布边界

## 先记住一条原则

页面没有链接、条目标记为 `private`，都不等于真正的访问控制。只要私人文字或原图进入公开 Git 仓库或最终静态构建产物，就可能被他人取得。

## 当前项目的安全默认值

- 未确认公开范围的文字、人物姓名、时间、地点和照片，不进入仓库；
- 私人简历不进入公开仓库、`public/` 或构建产物；
- 不把密码、身份证明、未获授权的联系方式、精确定位或原始私密媒体写入 Markdown；
- 环境变量和密钥只放在部署平台，不提交到 Git。

内容的可见性字段是审核护栏，不是身份验证系统。

## 当前发布方式

本站是公开的 GitHub Pages 静态网站，只保存明确允许公开的素材。仓库中不保存未公开原稿。需要受保护存储的个人材料应留在站点之外，不使用前端密码假装访问控制。

## 素材进入项目之前

每份准备公开的素材至少确认：

1. 作者与所有出镜者是否同意公开；
2. 可公开到什么范围；
3. 是否需要隐藏真实姓名、日期或地点；
4. 原图是否包含定位、设备等元数据；
5. 撤回后需要删除哪些源文件和构建产物。

公开许可尚未确认时，不录入真实私人内容。
