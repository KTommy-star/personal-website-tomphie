# Tomphie 网站内容提供指南

不需要一次准备齐全部材料。建议每次只完成一个模块，并优先提供真实原稿；我会负责整理结构、润色网页文案和适配版式。

## 1. 首页与个人名片

请提供：

- 中文姓名、英文名或希望公开使用的名字
- 当前身份、学校或单位、专业或研究方向
- 所在城市，以及是否希望公开
- 80–150 字个人介绍
- 一张正式头像或一张更能代表你的照片
- 如需整理简历，请单独私下提供，不默认放入公开站点
- 邮箱、GitHub 和其他希望公开的主页链接
- 最近正在关注或推进的三件事

## 2. 人生轨迹

每段求学或实习经历使用下面的格式：

```text
名称：
类型：求学 / 实习 / 重要经历
起止时间：
地点：
当时的身份：
主要经历：
最想保留的一段故事：
关联项目或科研：
可公开图片：
```

## 3. 科研

请提供：

- 研究方向与关心的问题
- 论文、报告、专利、数据集、代码或竞赛成果
- 每项成果的状态：已发表、投稿中、进行中或已完成
- 作者、摘要、引用格式和相关链接
- 你在其中承担的具体工作
- 可以公开的图表、实验截图或演示材料

## 4. 项目

每个项目尽量包含：项目背景、目标、你的角色、协作者、技术方案、关键困难、最终结果、复盘、截图、演示链接和代码仓库。首批选择三到六个代表项目即可。

## 5. 笔记知识库

请先提供：

- 希望长期记录的三到六个主题
- 已有文档的原始格式，例如 Markdown、Word、PDF 或飞书导出
- 一篇最接近最终质量的代表笔记
- 哪些内容可以公开，哪些仅用于整理

## 6. 恋爱珍宝库

GitHub Pages 不提供真正的私密访问控制。真实私人素材进入项目前，请先阅读 `docs/privacy-and-publishing.md`。

添加任何私人内容前，请先和伴侣共同确认：

- 采用公开精选版，还是需要真实身份验证的私密版
- 可以公开的人物、地点、日期和照片范围
- 明确不能公开的内容
- 第一批想保存的三到五段回忆
- 希望呈现的情绪，以及不喜欢的浪漫表达方式

每段回忆可以从日期、地点、事件、照片、物件、文字和双方公开许可七项开始整理。

## 7. 视觉与动效偏好

请提供三到五个喜欢的网站或页面，并分别说明喜欢的是布局、字体、颜色、图片使用还是滚动动画。也请提供明确不喜欢的风格，这通常比“高级感”一类抽象形容更有帮助。

## 8. 图片与授权

- 尽量提供原图，不先压缩或截图。
- 标明图片拍摄者、人物和是否允许公开。
- 含伴侣、朋友、学校或单位内部信息的图片，需要确认公开范围。
- 私密原图不会默认进入公开构建产物。
