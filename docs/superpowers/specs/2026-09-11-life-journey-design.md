# 人生轨迹模块设计

日期：2026-09-11  
状态：已确认，进入实施

## 1. 目标

将求学、学生工作与职业起点组织成一条持续生长的个人路线。页面不是简历列表，也不是地图软件界面，而是一幅“抽象地理轨迹 + 章节叙事”的滚动长卷。

## 2. 内容边界

公开叙事只使用已经确认的信息：

- 广东东莞：出生坐标。
- 重庆铜梁：成长阶段，学校顺序为水霖学校、实验一小、巴川中学。
- 四川成都：2024.09 至今，就读电子科技大学软件工程专业。
- 大学学生工作：一路工作室副主席、信息与软件工程学院创新创业中心助理、电子科技大学小城大爱实践队成员、软件 e 声摄影部部长。
- 腾讯：仅表示已获得 Offer、尚未开始实习，归类为重要里程碑，不归类为实习经历。
- 当前研究关注：多模态、缺失模态、医学深度学习、Agent、具身智能。

未确认的中小学日期、学生工作日期、具体职责和故事不得推测。电话、生日、成绩排名、私人简历路径不得进入页面或构建产物。

## 3. 叙事结构

页面由七幕连续组成：

1. 序章：从东莞出发，沿着成长来到成都。
2. 东莞：以留白和抽象地图纹理建立起点。
3. 铜梁：地图局部放大，三所学校以连续年轮/刻度展开。
4. 成都：电子科技大学成为核心主节点，介绍软件工程学习与 AI 方向探索。
5. 大学之外：四项学生工作合并成一个章节，从中心节点展开四条支线。
6. 腾讯 Offer：以空心节点和虚线路径表达“已收到邀请、尚未抵达”。
7. 当前坐标：总结当前身份与关注方向，并导向科研和项目栏目。

## 4. 页面构图

桌面端采用约 40% / 60% 双栏：左侧为 sticky 抽象地图，右侧为正常文档流中的章节。地图不绘制精确行政边界或私人坐标，而使用三个城市标签、路径曲线、编号和网格构成个人地图。章节进入视口时，地图同步高亮对应坐标并更新路线进度。

移动端取消 sticky 双栏，改为单列时间线。每个章节顶部显示对应的微型路线切片，保证不依赖横向空间或嵌套滚动。

## 5. 视觉语言

- 继承全站纸白、墨黑、静灰和路径蓝。
- `TOMPHIE` 镂空字形作为大型地形轮廓横跨序章与地图背景，但不遮挡正文。
- 使用坐标编号、细网格、路径刻度、空心/实心节点建立档案感。
- 不使用统一圆角卡片、玻璃拟态、地图图钉、渐变光效或自动播放媒体。
- 已走过的路线为实线；腾讯 Offer 之后为虚线并延伸出画面。

## 6. 交互

- 顶部筛选为“全部 / 求学 / 学生工作 / 里程碑”。筛选只改变展示密度，永远保留地点主线。
- 滚动章节时更新地图的活动节点、路线填充和章节序号。
- 学生工作四条支线使用原生 `details` 展开，键盘和触摸均可操作；默认收起具体说明，因为当前尚无已确认职责正文。
- 腾讯 Offer 节点不可写成实习，也不链接虚构内容。
- 关闭 JavaScript 后仍显示完整章节；筛选按钮在脚本不可用时不隐藏内容。
- `prefers-reduced-motion: reduce` 下取消滚动绑定、漂移和路径生长，直接显示最终路线。

## 7. 数据结构

首版使用 `src/data/journey.ts` 保存已确认的展示数据和分组关系。它只承担轨迹页的策展结构，不修改现有 Astro 内容集合，也不创造虚假的精确日期。未来获得完整日期与故事后，可将单项经历迁移到 `src/content/journey/`，页面接口保持一致。

## 8. 降级与无障碍

- 抽象地图是增强视图，右侧时间线是完整事实来源。
- 活动状态除颜色外还通过节点尺寸、实线和文字标签表达。
- 筛选按钮使用 `aria-pressed`，章节使用语义化标题，学生工作使用 `details/summary`。
- 所有触控目标至少 44px，375px 宽度无横向溢出。

## 9. 验收标准

- 页面准确出现东莞、铜梁、成都及正确学校顺序。
- 四项学生工作位于同一章节内，不占据四个主时间轴节点。
- 腾讯明确显示“已获得 Offer，尚未开始实习”。
- 桌面端地图与章节滚动联动，移动端为完整单列时间线。
- 分类筛选、键盘操作、无 JavaScript 阅读和减少动态效果模式均可用。
- 构建产物不包含私人简历路径、电话、生日或成绩排名。
- Astro 类型检查、单元测试、生产构建和构建产物测试全部通过。

## 10. 首版不做

不接入第三方地图、不公开精确坐标、不加入实际不存在的实习内容、不为缺失日期和故事编写占位假文案、不引入 React 或新的运行时依赖。
