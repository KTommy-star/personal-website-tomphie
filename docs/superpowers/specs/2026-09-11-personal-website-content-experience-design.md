# 个人网站内容与体验设计

日期：2026-09-11  
状态：待用户审阅

## 1. 项目定位

这不是一份放到网页里的简历，而是一套可以持续生长的个人数字档案。网站同时服务三类访客：

1. 老师、研究者与招聘者：快速确认专业背景、研究方向和项目能力。
2. 同学、朋友与普通读者：理解个人经历，并阅读长期积累的知识内容。
3. 自己与伴侣：保存具有情感价值、适合长期回看的共同记忆。

全站的核心叙事是“个人坐标 / 人生轨迹”：地点构成经历，研究与项目构成探索，笔记构成思想路径，恋爱珍宝库构成共同生活留下的坐标。

设计目标按优先级排列：

1. 真实地表达一个具体的人，而不是套用个人主页模板。
2. 专业内容容易找到、容易阅读、可以被搜索和分享。
3. 通过自然滚动和少量关键动画形成记忆点。
4. 各栏目气质可以变化，但仍明显属于同一个网站。
5. 内容可以由 Markdown 等简单文件长期维护，不依赖复杂后台。

## 2. 全站信息架构

主导航采用清楚的中文名称，不用过度诗化的栏目名：

- 首页
- 人生轨迹
- 科研
- 项目
- 笔记
- 珍宝库

“简历下载”“联系方式”“GitHub 等外部主页”放在首页和全站页尾，不单独占用主导航。

### 2.1 首页：个人名片与全站入口

首页的任务是在短时间内回答：你是谁、你现在关注什么、访客接下来值得看什么。

内容顺序：

1. 首屏：姓名、当前身份、一句具体而克制的自我说明。
2. 当前坐标：所在城市、学习或研究阶段、近期关注方向。
3. 人生路径预览：选取三到五个关键地点或阶段。
4. 精选研究与项目：只展示最能代表能力的内容。
5. 最近笔记：显示持续更新，而不是静态简历。
6. 私人一面：以含蓄入口连接珍宝库，不在首页暴露私人内容。
7. 联系区：邮箱、简历、GitHub 与其他确定需要的渠道。

首页的标志性动画是“坐标点变成路径”：一个代表当前身份的点随着滚动延伸成路线，并依次连接经历、研究、项目和笔记入口。即使动画关闭，所有标题和入口仍按正常文档顺序完整呈现。

### 2.2 人生轨迹：求学与实习地图

求学地图和实习地图合并成一张可筛选的“人生轨迹”，避免两个结构重复的页面。

内容组成：

- 地图：展示地点之间的关系。
- 时间轴：展示先后顺序，是地图失效时的完整替代视图。
- 图层筛选：求学、实习、重要经历；未来有足够内容时再增加其他类型。
- 节点详情：时间、地点、身份、做过的事、一段个人记忆、相关研究或项目。

桌面端可以使用“左侧固定地图 + 右侧滚动故事”，当前故事进入视口时对应地点自然高亮。移动端改为普通纵向时间轴，在每个节点内嵌静态地图或小地图，避免嵌套纵向滚动。

### 2.3 科研：正式成果与研究过程

科研栏目需要同时满足专业访问和个人记录，但两者在层级上分开。

内容顺序：

1. 研究简介：目前关注的问题与方向。
2. 代表性成果：论文、报告、数据集、开源代码或其他正式产出。
3. 进行中的探索：允许展示状态，但必须明确标注“进行中”。
4. 科研笔记入口：方法总结、论文阅读、实验复盘等过程型内容。
5. 学术简历与联系方式。

每项正式成果包含：标题、时间、状态、作者信息、摘要、个人贡献、相关链接和引用信息。科研页面以阅读和可信度为主，只使用轻量淡入、状态切换和关系连线，不安排长时间锁屏动画。

### 2.4 项目：案例而不是卡片墙

项目首页先展示三到六个代表项目，其余项目进入可筛选列表。重要项目拥有独立案例页。

每个案例按以下顺序组织：

1. 项目背景与要解决的问题。
2. 自己承担的角色和边界。
3. 关键过程、选择与困难。
4. 最终产出、演示或截图。
5. 可量化结果与复盘。
6. 相关笔记、代码或研究成果。

动效主要用于解释过程：原型到成品的对比、系统结构逐层出现、结果随滚动切换。没有解释价值的装饰动画不进入项目页。

### 2.5 笔记：可持续维护的个人知识库

笔记区采用“知识库”而不是传统按日期排列的博客首页。

主要入口：

- 主题：按研究、编程、学习方法等领域浏览。
- 系列：按课程、专题或长期学习路径连续阅读。
- 最近更新：发现新内容。
- 搜索：从标题、摘要、正文和标签检索。

桌面端使用可收起的知识目录与正文布局；移动端目录变为正文顶部的章节入口。文章之间允许建立“前一篇 / 后一篇”“所属系列”“相关研究 / 项目”等联系。

正文优先保证中文长文阅读，不使用持续滚动特效。代码、公式、图片和引用拥有统一样式；文章标题、更新时间、阅读进度和目录可以使用轻量交互。

### 2.6 恋爱珍宝库：全站中的独立情感空间

珍宝库共享全站导航、基础排版和可访问性规则，但拥有页面级的色彩、字体和动效覆盖。它不改变成另一个网站，而像进入同一座档案馆中更私密的一间房。

内容分为五种组织方式：

1. 时间：相识、纪念日和共同经历。
2. 地点：旅行、生活与重要事件发生的地方。
3. 见闻：完整的故事文章。
4. 物件：照片、票根、礼物、手写内容等数字藏品。
5. 信件：适合独立阅读、可选择延时公开或始终私密的文字。

推荐体验是“记忆章节”：每个章节围绕一个地点、物件或时间展开，滚动时图像、文字与细节逐步建立关系。不会使用自动播放的背景音乐或无法暂停的循环动画；音频如需要，由访客主动播放。

珍宝库在实施前必须选择隐私模式：

- 公开精选版：内容经过双方确认，可随网站静态发布。
- 私密完整版：使用真正的身份验证和受保护存储，不把原始内容打包进公开的 GitHub Pages 文件。

仅在前端设置密码不能形成真实隐私边界，因此私密完整版需要独立于纯静态部署的技术方案。

## 3. 视觉设计语言

全站基调定义为“清晰、克制、精确，但保留人的温度”。不直接复制 Apple 的字体、组件或产品页，而借鉴它对空间、节奏、材质和信息焦点的处理。

### 3.1 基础视觉系统

- 基础色：墨黑 `#111111`、纸白 `#F7F7F5`、静灰 `#686864`、分隔线 `#D8D8D2`。
- 全站强调色：路径蓝 `#2457FF`，单个页面只使用一个主要强调色。
- 珍宝库强调色：深玫瑰 `#9B4257`，只在该栏目内使用。
- 正文与界面：Noto Sans SC 或等价的本地中文无衬线字体栈。
- 少量英文展示文字与数字：Newsreader；珍宝库的信件正文可使用 Noto Serif SC。
- 桌面采用十二列、移动端采用四列网格；长文正文控制在约 65–75 个字符的舒适阅读宽度。

图片、地图和文字是主要视觉内容，不以渐变、玻璃拟态、发光或统一圆角卡片作为装饰。全站只选择一个最有辨识度的视觉动作：路径的生成与连接。

### 3.2 导航与页面关系

顶部导航保持位置稳定。初始状态尽量轻，内容滚动到导航下方后再出现清楚的背景与分隔，使其与内容建立层级。深层页面始终提供当前位置、返回栏目和下一步阅读入口。

页面之间采用短促的淡入与轻微位移保持空间连续性；不播放完整的“过场动画”，不让用户等待。

## 4. Apple 式滚动与动效系统

Apple 式体验的重点不是动画数量，而是动作自然地响应滚动、始终有空间逻辑，并让内容成为焦点。Apple 的 Human Interface Guidelines 同样强调动效应有目的、反馈应简短精确、动画应可取消，并对减少动态效果的偏好作出响应：

- [Apple Human Interface Guidelines: Motion](https://developer.apple.com/design/human-interface-guidelines/motion)
- [Apple Human Interface Guidelines: Scroll views](https://developer.apple.com/design/human-interface-guidelines/scroll-views)
- [Apple Reduced Motion evaluation criteria](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/reduced-motion-evaluation-criteria)

### 4.1 动效原则

1. 保留浏览器原生滚动，不做 scroll-jacking，不改写滚轮距离。
2. 滚动只控制视觉状态，不控制用户是否有权继续阅读。
3. 一屏只建立一个焦点，其他元素保持安静。
4. 只在叙事需要时短暂使用 sticky 场景；普通长文不固定屏幕。
5. 位移、缩放和透明度承担大部分动画，避免引发布局重排的属性。
6. 所有滚动场景都有清晰的开始、变化和最终状态；快速滚动时可以直接到达最终状态。
7. 动画不能承载唯一信息，关闭 JavaScript 后仍有合理的阅读顺序。
8. `prefers-reduced-motion` 下取消视差、滚动绑定和大幅缩放，改为静态排版或简短淡入。

### 4.2 动效层级

- 一级：全站标志性叙事。仅首页路径生成、人生轨迹、珍宝库章节使用。
- 二级：页面状态变化。筛选、目录展开、项目过程切换等，反馈简短明确。
- 三级：基础交互。按钮、链接、图片查看等，只提供必要的悬停、按下和焦点反馈。

### 4.3 各栏目动效配额

- 首页：一个连续的路径叙事，不再给每个区块重复添加入场动画。
- 人生轨迹：地图位置、路线和时间轴联动。
- 科研：轻量揭示和关系提示，优先保证快速扫描。
- 项目：动效用于解释设计或技术过程。
- 笔记：接近静态阅读，仅保留目录、搜索和阅读状态。
- 珍宝库：动效最丰富，但每个章节仍只有一个主要动作。

### 4.4 设计自审后的取舍

初步风格检索给出了“滚动叙事 + 粗野主义”的组合。滚动叙事与人生轨迹匹配，因此保留；粗野主义会削弱科研可信度和中文长文阅读，因此改为克制的档案式底层设计。项目页不使用同质化卡片矩阵，珍宝库也不套用常见的粉色渐变与漂浮爱心。Apple 只作为动作逻辑和节奏参考，不复制其产品页外观。这样每个主要选择都来自本站的真实内容，而不是通用个人主页模板。

## 5. 内容模型与关联

所有可发布内容共有字段：标题、短摘要、发布日期、最后更新、封面、标签、可见性、草稿状态、相关内容和稳定链接。

各类内容增加以下字段：

- 轨迹节点：起止时间、地点、经纬度、类型、身份、故事、媒体、关联成果。
- 科研成果：成果类型、状态、作者、引用、摘要、个人贡献、论文/代码/数据链接。
- 项目：问题、角色、过程、技术、结果、媒体、演示与仓库链接。
- 笔记：主题、系列、章节顺序、目录、参考资料、关联研究或项目。
- 珍宝：日期、地点、故事类型、媒体、双方公开许可和可见性。

关联关系用于产生自然的探索路径，例如：某段实习经历连接到一个项目，该项目连接到一篇复盘笔记；某个科研成果连接到实验日志和论文阅读笔记。

## 6. 实施模块与新对话边界

后续建议拆成八个独立对话。每个对话开始时先读取本设计文档，且只修改自己负责的页面和共享接口。

| 模块 | 对话范围 | 主要交付 | 依赖 |
|---|---|---|---|
| 0. 全站基础 | 技术骨架、内容模型、设计令牌、导航、页尾、动效令牌 | 可运行的空站框架与共享组件 | 无 |
| 1. 首页 | 个人名片、精选入口、路径叙事 | 完整首页 | 模块 0 |
| 2. 人生轨迹 | 地图、时间轴、筛选和节点详情 | 求学与实习轨迹页 | 模块 0 |
| 3. 科研 | 研究简介、成果列表、成果详情、科研笔记入口 | 学术主页 | 模块 0 |
| 4. 项目 | 项目索引、筛选、案例页 | 项目作品集 | 模块 0 |
| 5. 笔记 | 知识目录、文章模板、搜索与关联 | 博客/知识库 | 模块 0 |
| 6. 珍宝库 | 隐私模式、章节结构、地点与物件体验 | 恋爱珍宝库 | 模块 0；先确认隐私模式 |
| 7. 全站整合 | 跨栏目关联、SEO、性能、无障碍、404、部署 | 可正式发布的网站 | 模块 1–6 |

依赖关系：

```text
模块 0 全站基础
    ├── 模块 1 首页
    ├── 模块 2 人生轨迹
    ├── 模块 3 科研
    ├── 模块 4 项目
    ├── 模块 5 笔记
    └── 模块 6 珍宝库

模块 1–6 完成后 → 模块 7 全站整合与发布
```

模块 1–6 在模块 0 稳定后可以分别开发。共享组件或设计令牌的修改回到模块 0 处理，避免多个对话同时各自创造一套导航、按钮或动效参数。

## 7. 降级、错误与隐私边界

- 地图加载失败时显示完整时间轴和地点文字。
- 动画初始化失败或被关闭时直接呈现最终内容，不显示空白场景。
- 搜索不可用时保留主题、系列与文章索引。
- 媒体缺失时保留固定比例和文字说明，避免页面跳动。
- 外部论文、演示或代码链接失效时显示可理解的状态，不删除正文背景。
- 珍宝库的私密内容在身份验证完成前不得下载到浏览器，也不得进入公开构建产物。
- 照片、书信和共同故事发布前应由双方确认公开范围。

## 8. 验收标准

### 内容

- 首页可以在一分钟内说明身份、方向和代表内容。
- 每个主栏目都有明确入口、空状态和返回路径。
- 研究、项目、轨迹和笔记之间可以互相关联。
- 草稿和私密内容不会进入公开页面或搜索索引。

### 体验

- 375、768、1024 和 1440 像素宽度下无横向溢出。
- 键盘可以访问全部导航、筛选、搜索和媒体控制。
- 减少动态效果模式下没有视差、滚动绑定或强制大幅缩放。
- 动画未加载时页面仍完整可读，地图失败时仍能浏览经历。
- 重要文本满足可读性与颜色对比要求。

### 性能

- 首屏不依赖大体积自动播放视频。
- 图片有明确尺寸并使用响应式格式，非首屏媒体延迟加载。
- 滚动场景不持续占用不可见页面的计算资源。
- 长文章、地图与珍宝库在移动设备上采用简化动画。

## 9. 明确不做的内容

首版不加入社交动态流、评论系统、用户账号体系、复杂内容管理后台、全站 3D 场景和无目的的自动播放媒体。除非珍宝库选择私密完整版，否则全站保持静态优先。

这些能力只有在真实内容与使用需求证明必要时，才进入后续版本。
