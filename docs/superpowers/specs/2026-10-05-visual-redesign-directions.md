# Tomphie 整体视觉重构：方向提案与工具约定

日期：2026-10-05
状态：用户已确认 A「折光山水」并授权实施；首版已重构首页与共享框架，保留真实内容、日夜模式及五栏目；验收记录见 `docs/design/refracted-landscape.md`

## 1. 本次范围与设计判断

本地已按用户要求取消一个栏目，保留首页、人生轨迹、科研、项目、笔记五个主要空间。本文件不包含被取消栏目的替代产品方案。私人简历继续留在站点之外。

现有首页依次是个人身份与大幅照片、长篇经历、研究方向与职务、栏目路线、联系方式。科研、项目和笔记主要是建设说明。设计感不足的关键是：信息量和视觉占比失衡，各段的排布节奏重复，品牌背景字与内容各自运动，缺少真实作品的视觉重心。新增模糊或更多入场动画并不能独立解决这些问题。

新版定位：一个有生活温度、研究可信度与作品辨识度的个人空间。访客先认识孔俊鑫 / Tommy，再理解他关注的问题与实际做过的事，最后沿经历和笔记继续探索。摄影与地点是个人辨识度来源，不虚构科研成果或项目。

## 2. 锚定工具，不以组件拼贴代替设计

| 工具 / 参考 | 本项目决定 | 理由与边界 |
| --- | --- | --- |
| Astro + 现有 Tailwind / TypeScript | 保留 | 内容、静态发布和现有路由可复用，不为改视觉迁移框架 |
| Motion 原生 JavaScript 版 | 已接入 14.0.0，唯一新增动效主库 | 同一体系处理即时按下反馈、物理弹性、SVG 与滚动关联；不依赖 React |
| GSAP / ScrollTrigger | 本轮不接入 | 强大的滚动编排备选；本项目更重视轻量、可打断的触控反馈，不维护两套动画生命周期 |
| gentpan/liquidglass 零依赖 SVG 引擎 | 2026-10-06 已固定 v1.0.0 来源并接入全站功能玻璃 | 独立背景副本的真实折射，不依赖 Chromium 专属的 SVG backdrop；静态自托管，不使用截图或其组件/动效体系 |
| 原生 CSS / SVG 玻璃材质 | 共享材质、边光与降级层 | 文字清晰、按压高光、减少透明度/高对比下仍可读可用；不是苹果原生 SDK |
| Lucide SVG | 图标来源 | 只按需取用导航、主题、复制、展开等图标；不替换个人 Logo，不引入整套图标运行时 |
| React Bits / Aceternity UI | 仅作为视觉技法参考 | 不直接复制成品区块，不引入 React 来拼装 Astro 页面 |
| Lusion | 参考视觉叙事的组织方法 | 借鉴内容与交互围绕一个焦点展开的思路，不复制其素材或要求全站 3D |

实施前已核查 Motion 14.0.0 与 liquidGL 3.0.0。Motion 精确固定进锁文件；liquidGL 官方说明 CSS 动画实时折射不受支持，因此不采用其截屏方式。2026-10-06 用户要求真实通透折射后，已改用固定版本的零依赖 SVG 光学引擎，具体版本、许可、性能策略与浏览器边界见 `docs/design/refracted-landscape.md`。不声称实现苹果原生自适应材质，不购买付费素材或 Motion+。

`apple-design` 已安装到 `/Users/kongsanjin/.codex/skills/apple-design`。它是 Emil Kowalski 仓库中的社区设计指导，不是 Apple 官方 SDK。采用其即时响应、空间连续性、可打断动作和无障碍原则；遇到兼容性或具体参数问题仍以官方文档和实际表现为准。

## 3. 三种视觉方向

### A. 折光山水 — 推荐

情绪：清透、有呼吸、有人味；像一座置于水岸上的当代玻璃展馆。

首屏不是纯色底加大字：以用户真实湖边照片和独立的水岸抽象背景建立横向空间，姓名与一句自述居左，人物和远处水面居右。薄而清澈的导航悬浮在背景上，人物不被玻璃或标题遮住。下方一条玻璃信息带承载学校、城市、研究入口，避免把所有职务塞到首屏。

初始色板：雾白 `#F2F6F7`、水墨 `#17252C`、水青 `#BCD7DC`、远山蓝 `#507D92`、信号蓝 `#2557C8`。这些是构图候选，不是未经检查的文字对比值。夜间另设计深水和低亮边光，而不是把白天图片简单调暗。

字体：中文界面与正文使用 PingFang SC / Noto Sans SC 无衬线栈；重点引言可少量使用 Songti SC / Noto Serif SC。拉丁名字使用同体系无衬线，手写气质由真实 Tomphie Logo 承担。

布局：非对称宽幅首屏 → 紧凑身份带 → 研究与精选作品交错展陈 → 地点路线预览 → 最新笔记 → 联系区。内容靠同一网格对齐，图片区与文字区有大小变化，正文不居中排成长句。

关键动作：Logo 短暂勾线但不挡内容；滚动时水岸画面缓慢改变取景，玻璃边缘产生轻微折光；作品预览从点击位置展开，返回沿原路径收起。TOMPHIE 背景字保留为低对比空间标识，不再反复裁切抢占每一段。

玻璃用途：导航、身份带、图片题签、筛选器、联系操作；项目说明与笔记正文使用清晰稳定的底面。

优势：湖边照片、山城成长、成都求学、AI 探索之间有统一的视觉理由。取舍：需要认真制作日夜背景并调试人物与文字的裁切位置。

### B. 光学实验室

情绪：冷静、精密、实验性；像一间以玻璃透镜观察信息的研究工作室。

首屏以一枚抽象的透明透镜为记忆点，折射细密的光线和轮廓场。姓名、软件工程背景、研究方向围绕它形成严格网格，个人照片缩成独立的身份窗口。图像是艺术隐喻，不伪装成真实实验结果或医学影像。

初始色板：瓷白 `#F4F7FB`、石墨 `#141B27`、银灰 `#B8C4D1`、冰蓝 `#C5DAF2`、电蓝 `#315DEC`。夜间使用石墨背景、低亮冷白边缘，不做满屏霓虹。

字体：PingFang SC / Noto Sans SC 与系统拉丁无衬线；数字、图注与公式按阅读用途排版，不用装饰性乱码。

布局：中央透镜首屏 → 研究问题索引 → 成果与实验过程 → 大幅项目演示 → 简短人生路径 → 知识目录与联系。研究和作品是主体，经历不与成果争夺篇幅。

关键动作：切换研究方向时局部光场与对应说明一起变化；打开项目时从预览窗口延展到详情；状态反馈快速、准确，弹性很少。透镜不无限追逐鼠标，触屏提供同等点击入口。

优势：最突出专业身份和技术感。取舍：生活温度较弱，对正式科研和项目材料的质量依赖更高。

### C. 光影手记

情绪：真实、温暖、可探索；像一本关于地点、摄影与成长的数字影像杂志。

首屏从用户真实照片开始，姓名作为小而明确的署名，透明玻璃题签浮在水面或天空的留白上。向下进入不同尺度的照片、地点与短文字，不把内容包装成同尺寸卡片。

初始色板：日光白 `#F7F6F3`、暖石黑 `#262A2D`、湖灰蓝 `#809AA6`、浅金 `#D8C9AE`、深海蓝 `#355D7A`。夜间转为低亮摄影画廊，保持照片原有肤色和明暗关系。

字体：短篇引言使用 Songti SC / Noto Serif SC，导航、正文、项目技术说明保持中文无衬线；真实 Logo 作为署名。

布局：宽幅照片开场 → 地点 / 经历短章节 → 研究与项目的展页 → 笔记目录 → 玻璃联系方式。长文不贴在照片上，移动端保留清晰的纵向阅读顺序。

关键动作：选择地点时摄影、简短故事与路线同步切换；作品册翻页使用空间连续的短过渡；图片题签与触摸反馈保持轻巧。

优势：最有个人气质，尤其适合摄影与生活记录。取舍：需要更多真实可公开的照片；要给科研内容足够明确的入口，避免访客误以为只有摄影作品。

## 4. 所有方向共享的内容框架

- 首页：个人身份、代表内容、经历预览、近期记录和联系方式；不是各栏目说明书。
- 科研：研究问题 → 真实成果 → 进行中的探索 → 科研笔记；清楚区分正式产出与兴趣方向。
- 项目：以大图或演示为入口，每个案例说明问题、个人角色、关键选择、结果与复盘。
- 人生轨迹：继续复用真实经历、地图与时间轴数据，重新设计版式与联动状态。
- 笔记：主题和系列入口、索引、长文阅读；目录、搜索和阅读进度可以用轻量玻璃操作层。
- 联系：保留邮箱、QQ、微信复制和 GitHub 链接；不给私人简历增加公开入口。

现在没有公开成果的区块不放虚构数据、假论文或示例项目。原型阶段用真实介绍与明确的待补充状态；完整首页的精选内容数量取决于用户后续材料。

## 5. 液态玻璃与动效的统一规则

用户所说的“大量玻璃”落实为贯穿全站的共享材质：中间通透、边缘有厚度与微弱折射、局部高光、必要时增加局部对比。不是给每张卡片盖上高强度白色模糊层。

Apple 原始说明将 Liquid Glass 用于浮于内容上的功能层。Clear 变体对背景与上层文字有条件要求；本网站借鉴其视觉与层级原则，不声称浏览器获得了苹果原生自适应材质。

- 不在玻璃容器内再叠玻璃按钮；同一视野不混杂厚重磨砂与清透玻璃风格。
- 文字与图标保持清晰，不让折射扭曲点击对象本身；照片背后的文字区域允许局部压暗。
- 首屏可有一个标志性视觉动作，按钮与面板随操作回应，不让所有模块同时摇晃、弹跳或自动漂浮。
- 点击按下即时反馈；展开与关闭从同一来源出发，连续操作不等动画播完。
- 页面和节点的进度直接对应滚动位置，不用拖尾弹性影响其真实性。
- 导航视觉高度约 52–60px，Logo 约 22–28px；触控命中区仍至少 44px，不再让 SVG 撑大顶栏。
- 手机保留玻璃质感与按压反馈，减少视差和并发折射，避免嵌套滚动。
- 适配 `prefers-reduced-motion`、`prefers-reduced-transparency`、高对比、键盘操作及无 WebGL 状态；媒体查询覆盖不足时允许用户切换简化效果。

## 6. 用户选定后的实施顺序

1. 固定一个主方向，再确定少量可融合的细节；不将三个方向的布局随意拼在一起。
2. 先做首屏 + 浮动导航 + 一项玻璃交互的可体验原型，同时展示浅色、深色和手机状态；确认视觉与折射质量。
3. 制作所选方向的背景资源：桌面和手机分别构图，日夜分别配色。抽象背景可以生成，个人照片不擅自替换人物、地点或伪造经历。
4. 统一布局、字体、玻璃、图标和动效令牌，更新本文件与协作约定，形成后续各模块的唯一设计依据。
5. 按首页、科研、项目、人生轨迹、笔记逐个改版，复用已有内容模型、主题和复制逻辑；不重写无关的发布配置。
6. 分阶段做手机 Safari / Chrome、平板与桌面的视觉、触控、性能及无障碍检查，确认后再发布。
