# Tomphie 私人写作工作台

状态：用户已确认唯一管理员账号密码、私密草稿跨设备同步、主动发布，并授权实施。

## 范围

工作台位于 `/admin/`，独立加载编辑器，不影响普通访客的首页体验。栏目只包含科研、项目、笔记。沿用折光山水配色、系统中文字体、日夜模式，正文与编辑区使用稳定底面。桌面使用目录、编辑、预览布局，手机在编辑和预览间切换。

## 架构

使用 Supabase Auth 托管密码验证，禁用公众注册，仅人工创建一个管理员。数据库中的唯一管理员记录与账号 UUID 绑定；前端用户名只作为该邮箱账号的别名，不能成为权限依据。数据库和私有图片桶均启用行级权限，只有该账号能读取和修改。避免自行实现密码散列、恢复和暴力破解防护。

私密草稿和图片保存在托管数据库、私有 Storage，不进入公开仓库。Supabase 发布函数每次验证真实用户与唯一管理员权限，从数据库读取指定版本，只复制明确确认发布的正文及其引用图片到 GitHub。GitHub 凭证仅配置于函数密钥，权限限定到本仓库。访客网站继续 Astro 静态构建和 GitHub Pages 自动部署。

技术选型是前述“托管认证与提交服务”的实现细化：不采用 Decap 的 GitHub 登录后端，不创建新的 GitHub 草稿分支，不将编辑草稿放入公开 Git 历史。第一版使用带格式工具栏的 Markdown 编辑与实时预览，不引入 React 或整套页面搭建器。

## 使用与状态

登录、记住设备、退出；无注册入口。三个栏目分别使用现有内容字段的表单。支持封面、正文图片、标题、列表、引用、代码、链接、公式。上传图片限制大小和类型，浏览器重编码减少体积并移除元数据。

自动保存私密草稿与主动保存相同；版本冲突不覆盖另一个设备的数据，保留当前正文并提示重新载入。切换文章、退出与离开页面必须处理尚未保存内容。发布前明确提示正文和引用素材将公开。

区分已修改、保存中、私密云端已保存、提交发布、等待部署、上线成功和部署失败。只有部署成功才能称为已上线；失败保留草稿和错误提示。已发布内容更新时沿用原栏目和链接，避免遗留旧公开页面。

## 安全与边界

正文预览去除可执行 HTML，链接限制安全协议，发布素材仅来自该管理员的私有桶。发布函数不接受客户端直接指定仓库、任意文件路径或公开内容快照。账号密码和后台密钥不进入聊天、Git 或构建产物。公开配置只含项目地址、公开 API key 和账号别名/邮箱；真正授权由 Auth 与数据库策略执行。

Supabase 免费套餐有容量、调用额度和不活跃暂停政策，不保证永久免费或无限容量。私密图片不会变成永久公共 URL，只有发布后的副本可公开访问。已经进入公开 Git 历史的内容无法承诺彻底撤回。

## 验收

未登录和非管理员拒绝草稿/图片访问和发布；私密保存不触发 GitHub 部署；并发保存拒绝旧版本；发布只写允许的文件和引用图片；列表详情只包含确认公开内容；编辑器不加载到普通首页。测试、类型检查、静态构建和有限浏览器检查。在线账号配置和真实发布需要用户自己的托管项目及密钥，不假造已部署结果。
